# Source Precedence

Foundation code must not reinterpret product, UX, editorial, visual, or architecture decisions.

1. PRD V1.0 — product/domain/rules/RF/RNF.
2. UX Master V1.0 — information architecture, flows, interaction and responsive behavior.
3. AMD-001 — narrow precedence for Content as a didactic unit and its expandable behavior.
4. Research Master V1.2 + Data Engineering Seed V1.2 — canonical Roadmap editorial content.
5. UI Master V1.0 — visual language, tokens, components, states and responsive baseline.
6. Architecture Master V1.0 — technical decisions for Foundation/implementation.

The Architecture Context Pack V1.0 is an operational handoff summary and never replaces a Master. A real conflict must be escalated to the appropriate source; it must not be silently “fixed” in code.
